# 중국어 탐험대 · 2주차 중간 복습 — 판다 저택의 다섯 개의 방 🏯

1~6차시를 한 번에 복습하는 **방 탈출형 게임**입니다. 복도에 문 5개가 있고, 학생이 **원하는 순서대로** 방에 들어가요.
방 안에서 반짝이는 ? 물건 3개를 눌러 문제를 풀면 보물 상자에서 🔑 열쇠가 나오고, 복도로 나와 다음 문을 골라요.
열쇠 5개를 모으면 복도 위쪽의 **보물의 문**이 열리고 끝나요. (방마다 3문제씩, 모두 15문제, 약 12~15분)

## 다섯 개의 방
| 방 | 차시 | 문제 1 | 문제 2 | 문제 3 |
| --- | --- | --- | --- | --- |
| 🎵 성조의 방 | 1차시 | 성조 금고: 妈·麻·马·骂 세 개 듣고 성조 번호 | 그림 액자: ma 소리 듣고 그림 고르기 | 국수 그릇: 面은 몇 성? |
| 👋 인사의 방 | 1·2차시 | 선생님께 老师好 | 인사말-그림 짝짓기(早上好·晚安·谢谢) | 对不起 → 没关系 |
| 🏷️ 자기소개 방 | 3·4차시 | 你叫什么名字？ 순서 맞추기 | 나라 이름-국기 짝짓기 | 안안의 자기소개 듣고 나라 고르기 |
| 🔢 숫자의 방 | 5차시 | 숫자 세 개 듣고 자물쇠 | 손숫자 사진 암호 | 四/十/七 구별 |
| 🎂 생일의 방 | 6차시 | 11월 9일 → 十一月九号 | 你的生日是几月几号？ 순서 맞추기 | 생일 듣고 카드 고르기 |

방마다 작게 반짝이는(✨) **숨은 물건** 2개가 있어요. 누르면 별 +10과 문화 이야기(성조, 早上好·再见, 王 성씨, 国, 520, 장수면, 시계 선물) 또는 손숫자 퀴즈가 나와요.
방의 세 문제를 모두 처음에 맞히면 보물 상자에서 **완벽 보너스**(별 +30), 아니면 별 +10.
끝난 학생은 **손숫자 스피드 도전**(한 번, 10문제)으로 별을 더 모을 수 있어요.

- **방 🔑** 칸: 클리어한 방 수. 학생 이름을 누르면 방에 들어간 순서와 문제별 첫 선택이 보여요.

## 고치고 싶을 때 (game-data.js)
- 문제 글자·보기·힌트: `zones` → 각 방의 `missions`
- 방 이름·색·주인 판다의 말: `name`, `door`, `wall`, `floor`, `host`, `hello`
- 물건 자리: `spot` / `deco` / `bonus`의 x(왼쪽에서 %), y(위에서 %)
- 문제를 빼고 싶으면 `{ id: ... }` 묶음을 통째로 지우면 돼요(방마다 1개 이상 남겨 두기).
- 점수: `points`
